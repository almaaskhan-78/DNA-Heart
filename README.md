# 🧬 DNA Heart

### A creative experiment combining code, animation, and visual design.

DNA Heart is a small interactive web experiment I created while exploring **HTML, CSS, and JavaScript**.

The idea was to combine a DNA-inspired visual with a heart concept and turn it into a creative coding project.

## ✨ Features

* 🧬 DNA-inspired visual design
* ❤️ Heart-themed concept
* ✨ CSS animations and styling
* 💻 Interactive web experience
* 🎨 Custom visual experimentation

## 🛠️ Built With

* HTML
* CSS
* JavaScript

## 🎯 Why I Built It

I wanted to experiment with using code as a creative medium rather than building only traditional websites.

This project helped me explore how **HTML, CSS, JavaScript, animation, and visual design** can work together to create something expressive.

## 🌱 What I Learned

* Structuring a creative web project
* Working with CSS animations
* Using JavaScript for interaction
* Combining design and code
* Experimenting with visual effects
